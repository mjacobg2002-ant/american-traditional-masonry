# American Traditional Masonry LLC

Marketing homepage for American Traditional Masonry LLC — paver, brick, stone, and concrete
masonry & hardscape serving Northern Virginia and the DMV.

- Static site: `index.html` + `css/styles.css` + `js/main.js` + `assets/`
- Background-video hero (`assets/video/hero-720.mp4`), full-color eagle logo (white version in the dark nav/footer).
- No build step. Open `index.html` or serve the folder.
